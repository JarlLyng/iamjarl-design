Icons

Usage

  • Phosphor on the web, SF Symbols in native apps. One set per app, never both.
  • In a native app, size a symbol with the text beside it, so it follows Dynamic Type; 20 and 24 are the web sizes.
  • Regular weight for core UI by default.
  • Duotone only for highlights and illustrations, not core navigation.
  • Don't mix icon weights on the same screen.
  • Default colour is text.primary; primary for active or emphasis; error for destructive.
